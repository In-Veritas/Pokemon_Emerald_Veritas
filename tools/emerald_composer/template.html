Emerald Composer

Compose music with the actual Pokémon Emerald (Veritas) instrument banks. Every instrument you hear is synthesized from the same samples and PSG voices the GBA sound driver uses, so what you write here is what the game will (approximately) play.

Workflow

  1. Pick a voicegroup (the per-song instrument bank the game will use).
  2. Add tracks (max 16 — this hack's BGM player limit), pick an instrument per track. Slot names ending in drum kit map one percussion sample per key.
  3. Draw notes on the piano roll. Space plays/stops.
  4. Export .mid, then register it in the game: 
    python tools/add_song.py path/to/mus_mysong.mid MUS_MYSONG --voicegroup NNN
    then build the ROM as usual. The exported MIDI is mid2agb-ready (24 PPQN, program changes = voicegroup slot numbers, CC7 volume, CC10 pan, loop markers).

Fidelity notes

DirectSound instruments use the exact sample data, loop points and m4a-style ADSR envelopes. PSG (square / wave / noise) channels are approximated with band-limited synthesis; envelopes are close but not bit-exact. The GBA's 8-bit output crunch is not simulated.
