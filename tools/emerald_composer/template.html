Quick guide

  1. Pick an instrument bank (voicegroup) in the transport bar. The label shows songs that use it in-game.
  2. Each horizontal track lane at the top is one instrument line, like tracks in a video editor. Click a lane (or its header) to select it; its notes open in the big note editor below.
  3. In the header set the track's instrument, volume and pan; M mutes, S solos.
  4. In the note editor: drag on empty space to draw a note, drag a note to move, drag its right edge to resize, right-click to erase. Click the piano keys on the left to preview the instrument.
  5. Space plays and stops. Click the ruler (in either view) to move the playhead.
  6. When it sounds right: File ▸ Export MIDI, then register it in the game (File ▸ "How do I put it in the game?").

Putting your song in the game

  1. File ▸ Export MIDI — you get mus_composed.mid. Rename it if you like.
  2. From the repo root run: 
    python tools/add_song.py path/to/mus_mysong.mid MUS_MYSONG --voicegroup NNN
    where NNN is the number of the instrument bank you composed with (shown in the transport bar, e.g. voicegroup051 → 51).
  3. Build the ROM as usual. Play it from any script with playbgm MUS_MYSONG, or set it as a map's music in that map's map.json.

The export is mid2agb-ready: 24 ticks per beat, program changes select voicegroup slots, CC7 = volume, CC10 = pan, and the loop markers [ ] make the song loop in-game.

Emerald Composer

A song editor for Pokémon Emerald Veritas that plays the game's actual soundfont: every instrument here is synthesized from the same samples, loop points, envelopes and GB sound channels the GBA driver uses.

Generated by tools/emerald_composer/build.py from the repo's sound data. Projects autosave to your browser every 30 seconds.
