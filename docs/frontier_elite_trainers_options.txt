FRONTIER ELITE TRAINERS — options reference
============================================

How to use: open frontier_elite_trainers.csv and fill each row. Leave any
column blank and I'll pick something sensible for it.

Encounter rule (already locked in, just FYI):
  12.5% chance per opponent slot on the LAST battle of any Battle Tower
  (Singles / Doubles / Multi) / Palace / Arena / Pike / Factory / Dome
  random-bracket run once the win streak in that facility is >= 14.
  Never replaces a Frontier Brain battle.


COLUMN 1 — Name
---------------
Up to 7 characters, uppercase (matches the rest of the pool, e.g.
JAXON, GRETEL, ZACHERY).


COLUMN 2 — Class
----------------
Pick one. Drives both the trainer's pic and how their name appears
("LADY KIM", "BLACK BELT TYRELL", etc.).

COLUMN 3 — Gender
-----------------
MALE or FEMALE. Some classes are inherently one (LADY = female, BLACK_BELT
= male, etc.); for the ambiguous ones (COOLTRAINER, PSYCHIC, EXPERT,
PKMN_BREEDER, PKMN_RANGER) this picks the pic variant. Defaults to MALE
if blank.


COLUMN 4 — AIFlags
------------------
Pick one preset:

  STANDARD  — vanilla Tower-trainer AI. Plays reasonably.
  ELITE     — recommended. Adds RISKY (will use risky moves like Focus
              Punch / Belly Drum / Sky Attack when it judges them safe).
  SETUP     — adds SETUP_FIRST_TURN. Good if the lead's first move is a
              boost (Dragon Dance, Bulk Up, Calm Mind, etc.).
  NUKE      — adds PREFER_POWER_EXTREMES. Always reaches for the highest-
              damage move. Good for raw-damage teams (Lucky Egg, Choice).
  SUN       — adds TRY_SUNNY_DAY_START. Good for sun teams.

  Or write a custom pipe-separated list from:
  CHECK_BAD_MOVE, TRY_TO_FAINT, CHECK_VIABILITY, HP_AWARE, RISKY,
  SETUP_FIRST_TURN, PREFER_POWER_EXTREMES, PREFER_BATON_PASS,
  TRY_SUNNY_DAY_START


COLUMN 5 — TeamTheme
--------------------
Freeform. Describe what the team should do; I'll pick the species, items,
moves, EVs, IVs, nature. Examples:

  "Mono-Steel defensive — Metagross lead, Skarmory + Forretress backline."
  "Rain stall — Politoed lead with Drizzle, Toxapex + Tentacruel + Ludicolo."
  "Fast offense — Salamence + Garchomp + Tyranitar, all Choice Banded."
  "Trick room — Dusclops sets TR, Rhydon + Slowking sweep."
  "Gimmick — every mon knows Explosion or Self-Destruct."
  "Counter-meta — has answers to the common top-tier picks."

Leave blank to let me pick a thematic team from the existing high-tier
slice of gBattleFrontierMons.


COLUMN 6 — Notes
----------------
Anything else: signature gimmick, fixed lead order, dialog tone, held-
item theme, lore hook, etc. Optional.
